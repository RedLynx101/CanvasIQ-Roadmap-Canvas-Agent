# Changelog

## 2.0.0

- Rebuilt the GUI as a responsive strategy workbench with light/dark themes and keyboard-accessible controls.
- Added validated monthly finance, explicit unknowns, funding/capacity scheduling, dependency blockers and disclosed portfolio-selection methods.
- Added scenario sensitivity, an evidence ledger, decision snapshots, local project switching and portable imports/exports.
- Replaced chat-text scraping with one bounded Agents SDK assistant and reviewable structured proposals.
- Added the `/canvasiq` skill, shared-engine CLI and nonexecuting Promethean discovery handoff.
- Reorganized the repository, documented deployment/data boundaries, and added domain/API/browser tests and CI.

The hosted demo is redeployed separately; repository version does not imply deployment status.
